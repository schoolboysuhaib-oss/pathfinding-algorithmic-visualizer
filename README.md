# Pathfinding Algorithmic Visualizer Matrix Engine (V1.0.0)

A high-performance graphical Python application utilizing Pygame to model real-time 2D network grids and animate discrete graph theory search traversals like Breadth-First Search (BFS).

## 🧮 Core Architecture & Features
* **Object-Oriented Node Structures:** Programmed modular node states (`Node`) capable of managing matrix row/column dimensions, pixel vector maps, obstacle states, and parent pointer tracks dynamically.
* **Graph Traversal Intelligence:** Implemented an active First-In, First-Out (FIFO) queue tracking matrix using specialized collections objects to efficiently parse grid neighbors layer by layer.
* **Real-Time Render Pipeline:** Designed an interactive 800x800 display surface updating cell boundaries and tracking horizons synchronously across 2,500 distinct structural array blocks.
* **Interactive CLI Matrix Control:** Integrated dynamic user mouse interrupts to seamlessly paint barriers, set targets, or reset the coordinate plane matrix via hardware keyboard keys on the fly.
